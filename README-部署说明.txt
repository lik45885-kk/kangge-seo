康哥亲投 Cloudflare Pages 预览包

1. 登录 dash.cloudflare.com，进入 Workers & Pages，创建 Pages 项目，选择直接上传。
2. 上传本ZIP压缩包（若界面要求文件夹，解压后上传含 index.html 的文件夹）。
3. 部署后使用 pages.dev 网址检查电脑/手机显示和按钮。
4. 本预览包设置 noindex,nofollow 和 robots.txt 禁止抓取，目的是避免商业服务页面在未确认主体及正式域名前被搜索引擎收录。
5. 现有Canonical和结构化数据仍指向旧workbuddy.host地址，正式上线前必须替换为自有域名。
6. 表单formKey为空，目前会尝试唤起访问者邮件客户端，不是后台自动收集线索；请不要将其当作正式线索表单。
7. 原始页面内容和设计保持不变，仅把robots meta改为noindex,nofollow并新增robots.txt。
8. 后续制作个人SEO学习站时应使用符合实际用途的内容，并重新设置index,follow、robots.txt、canonical、sitemap.xml。
